Site Plan – Developer Portfolio

Site Name

DevPath by Josue

This name combines the words "Dev" (developer) and "Path" (journey), representing my personal journey in software development, web technologies, and related projects. It communicates growth, learning, and a clear direction in my tech career.

Optional domain (not required for this class): devpathbyjosue.com (or devpath-jq.dev)

Site Purpose

The primary purpose of this website is to serve as my professional developer portfolio. It will:

  • Showcase my web development and software projects with clear descriptions and links to live demos or repositories.
  • Provide a short professional bio and highlight my technical skills and technologies I work with.
  • Offer an easy way for potential employers or clients to contact me through a simple contact form or direct links (email, LinkedIn).
  • Demonstrate clean, responsive, and accessible web design principles learned in this course.

Scenarios

These are example questions that my target audience (recruiters, hiring managers, or collaborators) might have:

  • Scenario 1: A recruiter wants to quickly see examples of my work and understand what kind of projects I can build. Question: “Where can I view your best projects with a short description and tech stack?”
  • Scenario 2: A hiring manager is considering me for a junior developer position. Question: “What technologies and programming languages do you know, and how can I contact you?”
  • Scenario 3 (optional extra): Another student or collaborator wants to connect with me for a project or study group. Question: “Do you have any social links (LinkedIn, GitHub) where I can follow your work?”

Color Schema

The color scheme is designed to feel modern, clean, and professional, with a focus on readability and subtle accents.

Primary Color

Hex: #1E88E5

Usage: Main headings, important buttons, and key links.

Secondary Color

Hex: #FFB300

Usage: Accent elements, highlights, badges, and hover states.

Background

Hex: #F5F5F5

Usage: Page background to provide a soft, neutral base.

Text

Hex: #212121

Usage: Main body text for good contrast and legibility.

Typography

The site will use two primary font families from Google Fonts to keep the design simple and consistent:

  • Poppins (sans-serif) – used for main headings (h1, h2, h3) and key UI elements like buttons.
  • Roboto (sans-serif) – used for body text, paragraphs, and longer descriptions.

Site Structure

The website will contain at least three main pages that share a common navigation, theme, and overall layout. The current plan is:

  • index.html – Home: Hero section with a short introduction, a summary of my skills, and featured projects.
  • projects.html – Projects: A dynamic list of projects loaded from a JavaScript array of objects, with filters and sorting.
  • contact.html – Contact: A form with validation and direct contact options (email, LinkedIn).
  • references.html – References: A simple page listing external sources used on the site.

JavaScript & Dynamic Behavior Plan

JavaScript will be used to create dynamic, interactive behavior across the site. Planned features include:

  • Dynamic project list: A JS array of project objects rendered with filter, map, and forEach, output via template literals.
  • Project filtering and sorting: Event listeners will update the displayed projects through conditional logic.
  • Theme toggle (light/dark mode): User preferences will be saved in localStorage and applied on page load.
  • localStorage usage: Store theme preference and last applied filter.

Form Plan

The contact form will follow HTML and accessibility standards presented in the course.

  • Fields: Name, Email, Reason for contact (select), Message.
  • Validation: Required fields, correct email format, minimum message length.
  • Feedback: JavaScript will prevent submission on errors and show a confirmation on success.

Performance, Accessibility & Progressive Enhancement

  • Lazy loading: All non-critical images will use loading="lazy".
  • Accessibility: Proper headings, descriptive alt text, color contrast, and focus states.
  • Responsive design: Mobile-first layout using CSS grid/flex.
  • Testing: DevTools (Console, Lighthouse, CSS Overview) will be used to evaluate performance, accessibility, SEO, and best practices.
